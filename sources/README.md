# Архив источников

Локальные копии документов, на которые ссылается справочник. Реестр всех источников — `docs/sources/index.md`.

## Что можно хранить

- Документы со свободной лицензией или с разрешения автора. Лицензию укажите в записи реестра.
- Собственные заметки и выжимки.

## Что нельзя хранить

- Официальные мануалы Sega и другие документы, защищённые авторским правом без разрешения на распространение. Для них — только ссылка и ссылка на копию в архиве (Wayback Machine).

## Как называть файлы

`<id-источника>.<расширение>`, где `id` совпадает с ID в реестре: например, `plutiedev-dma.html`.

Крупные бинарные файлы (PDF, ZIP) идут через Git LFS (см. `.gitattributes`).
