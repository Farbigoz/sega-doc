## Дополнительно для Claude Code

- Для проверки вёрстки запускай `mkdocs serve` в фоне и открывай страницу во встроенном браузере.

- Большие задачи (заполнить целый раздел) лучше дробить: одна страница — одна задача, со сверкой по источникам.
