# О проекте

Открытый справочник по разработке под Sega Genesis / Mega Drive на русском языке.

## Зачем

Информация о разработке под Mega Drive разбросана по форумам, старым сайтам и PDF-файлам, часть ресурсов уже недоступна. Здесь она собирается в одном месте, с понятными объяснениями, примерами кода и ссылками на первоисточники.

## Принципы

- **Каждый факт прослеживается до источника.** У страниц есть видимый статус проверки.
- **Примеры, которые работают.** Полные примеры собираются и проверяются в эмуляторе.
- **Наглядность.** Схемы, скриншоты и интерактивные модели там, где текста мало.
- **Один источник — два вида.** Те же файлы читаются на сайте и в Obsidian.
