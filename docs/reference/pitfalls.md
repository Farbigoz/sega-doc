# Подводные камни

Частые ошибки и неочевидное поведение, собранные в одном месте. У каждого пункта — ссылка на страницу с подробностями.

## Графика

- **Цвет 0 прозрачен в каждой палитре.** Им нельзя рисовать чёрный контур. → [Палитры](../hardware/vdp/palettes.md)
- **Больше 15 цветов на тайл или больше 4 палитр на экран** не влезет. Учитывайте это ещё при рисовании. → [Палитры](../hardware/vdp/palettes.md)
- **Тайл 0 должен быть пустым**: пустые клетки таблиц показывают его. → [Раскладка VRAM](../hardware/vdp/vram-layout.md)
- **Тайлы, заехавшие на таблицу**, портят и графику, и таблицу. → [Раскладка VRAM](../hardware/vdp/vram-layout.md)

## Спрайты

- **Порядок тайлов в спрайте — по столбцам**, а не по строкам. → [Спрайты](../hardware/vdp/sprites.md#порядок-тайлов-в-спрайте)
- **Координаты спрайтов со смещением +128.** → [Спрайты](../hardware/vdp/sprites.md#смещение-128)
- **У последнего спрайта цепочки должен быть `link = 0`**, иначе VDP пойдёт по мусору. → [Спрайты](../hardware/vdp/sprites.md#связный-список)
- **Спрайт 0 рисуется всегда.** Чтобы спрятать, его ставят за экран. → [Спрайты](../hardware/vdp/sprites.md#связный-список)
- **Лимит спрайтов на строку**: лишние пропадают без предупреждения. → [Спрайты](../hardware/vdp/sprites.md#ограничения)
- **Спрайт с P=0 впереди списка** может спрятать за тайлом с P=1 и спрайт с P=1. → [Приоритеты](../hardware/vdp/priority.md#спрайты-между-собой)

## Скроллинг

- **Знаки скролла разные**: `hscroll` растёт — картинка вправо, `vscroll` растёт — вверх. → [Скроллинг](../hardware/vdp/scrolling.md)
- **Камера быстрее 8 пикселей за кадр** — при подгрузке уровня надо дописывать несколько столбцов. → [Длинный уровень](../cookbook/level-streaming.md)

## VRAM, DMA и тайминги

- **Большие записи в VRAM во время отрисовки** медленные и «рвут» кадр. Всё через буфер и DMA в VBlank. → [Кадр, VBlank и прерывания](../hardware/vdp/timing.md)
- **Источник DMA не должен пересекать границу 128 КБ.** → [DMA](../hardware/vdp/dma.md#ограничение-128-кб)
- **Длина DMA — в словах**, а не в байтах. → [DMA](../hardware/vdp/dma.md)
- **Команда адреса VDP — два слова.** Прерывание, пишущее в VDP между ними, всё ломает. → [Порты и команды](../hardware/vdp/ports-and-commands.md#подводные-камни)

## Запуск на железе

- **TMSS**: на консолях с TMSS ROM должен записать `'SEGA'` в `$A14000`, иначе VDP не заработает. Многие эмуляторы это не проверяют. → [TMSS](../hardware/tmss.md)
