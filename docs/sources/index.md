# Источники

Реестр первоисточников. Каждый источник имеет **ID** (якорь в заголовке, например `{#plutiedev}`). Этот ID указывается во frontmatter страниц в поле `sources`. Сборка проверяет, что все ID из страниц есть в этом реестре.

Как добавить источник — см. [Правила оформления](../about/conventions.md#источники).

> [!warning] Ссылки ещё не проверены
> Список составлен по памяти во время первого обсуждения. Адреса нужно проверить, для мёртвых — найти копию в Wayback Machine и записать в поле «Архив».
