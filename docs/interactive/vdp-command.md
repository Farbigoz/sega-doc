# Калькулятор команд VDP

Считает 32-битную команду, которую нужно записать в порт управления `$C00004`, чтобы читать или писать память VDP по заданному адресу, и разбирает готовую команду обратно. Как устроена команда — на странице [Порты и команды](../hardware/vdp/ports-and-commands.md#установка-адреса-команда-из-двух-слов).

> [!note] Только на сайте
> Калькулятор — это скрипт и работает только на сайте. В Obsidian на его месте пусто.

## Команда → адрес

Можно ввести и слово записи в регистр, например `$8174`.

## Проверочные значения

Из страниц справочника:

| Что | Команда |
|---|---|
| VRAM, запись, `$0020` (тайл №1) | `$40200000` |
| VRAM, запись, `$C18A` (клетка (5, 3) Plane A) | `$418A0003` |
| VRAM, запись, `$DC00` (таблица HScroll) | `$5C000003` |
| CRAM, запись, `$0000` | `$C0000000` |
| VSRAM, запись, `$0000` | `$40000010` |
