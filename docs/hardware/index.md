- [Z80](z80.md) — сопроцессор, обычно для звука
- [VDP](vdp/index.md) — видеочип: тайлы, планы, спрайты, скролл, DMA
- [Звук](sound/index.md) — YM2612 и PSG
- [Ввод](io.md) — контроллеры и порты
- [TMSS](tmss.md) — защита Trademark Security System
