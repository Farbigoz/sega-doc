# Window

Window — третий слой из тайлов. Он **не скроллится** и показывается **вместо Plane A** в заданной прямоугольной области у края экрана. Типичное применение — HUD: счёт, жизни, время.

## Как устроено

- Таблица Window имеет тот же формат, что и [таблицы планов](planes.md#таблица-имён): слово на клетку, те же поля P, PAL, V, H, номер тайла.
- Адрес таблицы задаётся [регистром](registers.md) `$03`.
- Ширина таблицы фиксирована и не зависит от размера планов: **64 клетки в H40, 32 клетки в H32**.
- Window всегда стоит на месте относительно экрана: [скролл](scrolling.md) на него не действует.
- В области Window слой Plane A **не рисуется** совсем. Plane B и спрайты видны как обычно.
- Тайлы Window берутся с того же склада, что и тайлы планов.

### Область Window

Область задаётся двумя регистрами — границей по горизонтали и по вертикали:

| Регистр | Что задаёт | Шаг |
|---|---|---|
| `$11` | граница по X и сторона: Window слева или справа от границы | 16 пикселей (2 клетки) |
| `$12` | граница по Y и сторона: Window сверху или снизу от границы | 8 пикселей (1 клетка) |

Пример: статус-бар внизу экрана высотой 4 клетки. Plane A под ним скроллится, а Window со счётом стоит на месте.

```
┌────────────────────────────────┐
│                                │
│   Plane A (скроллится)         │
│                                │
├────────────────────────────────┤ ← граница по Y
│ Window: SCORE 001200  ♥♥♥      │
└────────────────────────────────┘
```

## Как с этим работать

Границу Window можно менять во время игры:

- **выезжающая панель или меню** — граница меняется на 1 шаг каждый кадр;
- через [HInt](timing.md#hint-горизонтальное) можно менять настройки Window посреди кадра.

> [!tip] Тряска экрана
> Для тряски Window не годится: шаг границы 8–16 пикселей слишком грубый. Тряску делают [скроллом](scrolling.md): добавляют ±1–2 пикселя к значениям скролла слоёв.
