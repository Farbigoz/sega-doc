# Раскладка VRAM

VDP не навязывает, что где лежит в VRAM: адреса таблиц задаются [регистрами](registers.md), а всё оставшееся место — под тайлы. Раскладку выбирают сами, соблюдая выравнивание и размеры таблиц.

## Как устроено

### Что лежит в VRAM

| Что | Размер |
|---|---|
| [Тайлы](tiles.md) | 32 байта на тайл |
| Таблица [Plane A](planes.md) | ширина × высота × 2 байта (64×32 → 4 КБ) |
| Таблица [Plane B](planes.md) | столько же, сколько Plane A |
| Таблица [Window](window.md) | 64 × 32 × 2 = 4 КБ в H40 |
| Таблица [спрайтов](sprites.md) | 80 × 8 = 640 байт в H40 |
| Таблица [HScroll](scrolling.md) | до 224 × 4 = 896 байт (построчный режим) |

### Пример раскладки

H40, планы 64×32:

```
$0000 ┌───────────────────────────┐
      │ Тайлы                     │  $0000–$AFFF: 1408 тайлов
      │ (тайл 0 — пустой)         │  (если Window не нужен — до $BFFF, 1536 тайлов)
$B000 ├───────────────────────────┤
      │ Window                    │  $B000–$BFFF, 4 КБ
$C000 ├───────────────────────────┤
      │ Plane A                   │  $C000–$CFFF, 4 КБ
$D000 ├───────────────────────────┤
      │ свободно                  │  2 КБ
$D800 ├───────────────────────────┤
      │ Таблица спрайтов          │  $D800–$DA7F, 640 байт
$DA80 ├───────────────────────────┤
      │ свободно                  │
$DC00 ├───────────────────────────┤
      │ HScroll                   │  $DC00–$DF7F, 896 байт
$E000 ├───────────────────────────┤
      │ Plane B                   │  $E000–$EFFF, 4 КБ
$F000 ├───────────────────────────┤
      │ свободно (128 тайлов)     │
$FFFF └───────────────────────────┘
```

Значения регистров для этой раскладки — в [примере инициализации](registers.md#пример-инициализации).

### Правила

- Каждая таблица должна начинаться с адреса, кратного своему выравниванию (см. [Регистры](registers.md#адреса-таблиц)).
- Таблицы не должны перекрываться между собой и с используемыми тайлами.
- **Тайл 0 оставляют пустым**: пустые клетки таблиц (слово `$0000`) показывают тайл 0.

## Подводные камни

- Тайлы, заехавшие на таблицу, превращаются в мусор на экране, а таблица — в мусор в графике. При росте числа тайлов следите за границей.
- Под тайлы на практике остаётся примерно 1300–1500 штук, а не 2048.
