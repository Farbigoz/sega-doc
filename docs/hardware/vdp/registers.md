# Регистры VDP

Регистры VDP задают режим экрана, адреса таблиц в VRAM, размеры планов, прерывания и параметры DMA. Запись — одно слово в порт управления: `$8000 | (номер << 8) | значение` (см. [Порты и команды](ports-and-commands.md#запись-в-регистр)).

## Обзор

| Регистр | Назначение |
|---|---|
| `$00` | режим 1: бит 4 — включить HBlank-прерывание (HInt) |
| `$01` | режим 2: бит 6 — дисплей вкл, бит 5 — VBlank-прерывание (VInt), бит 4 — DMA, бит 3 — V30, бит 2 — режим 5 |
| `$02` | адрес таблицы Plane A |
| `$03` | адрес таблицы Window |
| `$04` | адрес таблицы Plane B |
| `$05` | адрес таблицы спрайтов |
| `$07` | [цвет фона](palettes.md#цвет-фона-backdrop): палитра × 16 + индекс |
| `$0A` | счётчик строк для HInt |
| `$0B` | режимы [скролла](scrolling.md#режимы) |
| `$0C` | режим 4: H32/H40, [shadow/highlight](shadow-highlight.md), interlace |
| `$0D` | адрес таблицы HScroll |
| `$0F` | [автоинкремент](ports-and-commands.md#автоинкремент) |
| `$10` | [размер планов](planes.md#размеры-планов) |
| `$11`, `$12` | граница [Window](window.md) по X и Y |
| `$13`–`$17` | параметры [DMA](dma.md): длина и адрес источника |

## Подробно

### $01 — режим 2

| Бит | Значение |
|---|---|
| 6 | 1 — изображение включено |
| 5 | 1 — включено прерывание VBlank (VInt) |
| 4 | 1 — разрешён DMA |
| 3 | 1 — 30 строк клеток (V30, только PAL), 0 — 28 (V28) |
| 2 | 1 — режим 5 (режим Mega Drive). Должен быть 1 |

Типичное значение `$74`: дисплей, VInt, DMA, режим 5.

### Адреса таблиц

Регистры `$02`, `$03`, `$04`, `$05`, `$0D`. Значение регистра — это адрес таблицы, сдвинутый вправо. У каждой таблицы своё выравнивание:

| Регистр | Таблица | Значение | Выравнивание адреса |
|---|---|---|---|
| `$02` | Plane A | адрес / `$400` | `$2000` |
| `$03` | Window | адрес / `$400` | `$800` (`$1000` в H40) |
| `$04` | Plane B | адрес / `$2000` | `$2000` |
| `$05` | спрайты | адрес / `$200` | `$200` (`$400` в H40) |
| `$0D` | HScroll | адрес / `$400` | `$400` |

### $0A — счётчик строк HInt

HInt срабатывает каждые N+1 строк, где N — значение регистра. Подробно — в [Кадр, VBlank и прерывания](timing.md#hint-горизонтальное).

### $0C — режим 4

| Бит | Значение |
|---|---|
| 7 и 0 | оба 1 — H40 (320 пикселей), оба 0 — H32 (256 пикселей) |
| 3 | 1 — режим [shadow/highlight](shadow-highlight.md) |
| 2–1 | interlace |

`$81` — H40 без shadow/highlight и interlace.

### $10 — размер планов

| Биты | Значение |
|---|---|
| 5–4 | высота: `00` — 32, `01` — 64, `11` — 128 клеток |
| 1–0 | ширина: `00` — 32, `01` — 64, `11` — 128 клеток |

`$01` — 64×32. Допустимые сочетания — в [Планах](planes.md#размеры-планов).

## Пример инициализации

Под [раскладку VRAM](vram-layout.md) с Plane A в `$C000`, Window в `$B000`, Plane B в `$E000`, спрайтами в `$D800` и HScroll в `$DC00`:

```m68k
VDP_CTRL    equ $C00004

VdpInitRegs:
    dc.w $8004      ; $00: HInt выключен
    dc.w $8174      ; $01: дисплей, VInt, DMA, режим 5, V28
    dc.w $8230      ; $02: Plane A  = $C000 ($C000 / $400  = $30)
    dc.w $832C      ; $03: Window   = $B000 ($B000 / $400  = $2C)
    dc.w $8407      ; $04: Plane B  = $E000 ($E000 / $2000 = $07)
    dc.w $856C      ; $05: спрайты  = $D800 ($D800 / $200  = $6C)
    dc.w $8700      ; $07: цвет фона — палитра 0, цвет 0
    dc.w $8A00      ; $0A: счётчик HInt
    dc.w $8B00      ; $0B: скролл на весь экран
    dc.w $8C81      ; $0C: H40
    dc.w $8D37      ; $0D: HScroll  = $DC00 ($DC00 / $400  = $37)
    dc.w $8F02      ; $0F: автоинкремент 2
    dc.w $9001      ; $10: планы 64×32
    dc.w $9100      ; $11: Window по X выключен
    dc.w $9200      ; $12: Window по Y выключен
VdpInitRegsEnd:

InitVdp:
    lea     VdpInitRegs, a0
    moveq   #(VdpInitRegsEnd-VdpInitRegs)/2-1, d0
.loop:
    move.w  (a0)+, (VDP_CTRL).l
    dbra    d0, .loop
    rts
```
