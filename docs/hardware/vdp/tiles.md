# Тайлы

Тайл (tile, pattern) — блок 8×8 пикселей, из которых строится вся графика Mega Drive: и фоны, и спрайты. Тайл хранит только **индексы цветов**, а конкретные цвета задаёт [палитра](palettes.md), которую выбирает тот, кто тайл использует.

## Как устроено

- 8×8 пикселей, **4 бита на пиксель**: индекс цвета 0–15 в палитре.
- Одна строка тайла — 4 байта (8 пикселей по 4 бита).
- Весь тайл — 8 строк × 4 байта = **32 байта**.
- Строки идут сверху вниз. Внутри строки **старший полубайт — левый пиксель**.
- Индекс **0 — прозрачный** пиксель.

```
Длинное слово строки        Пиксели слева направо
$11222211            →      1 1 2 2 2 2 1 1
$12333321            →      1 2 3 3 3 3 2 1
```

### Номер тайла

Тайлы лежат в VRAM подряд, номер тайла — это его адрес, делённый на 32:

```
номер тайла = адрес в VRAM / 32
адрес тайла = номер × 32          (тайл №5 → $00A0)
```

Номер тайла занимает 11 бит, поэтому теоретический максимум — 2048 тайлов (64 КБ / 32). На практике часть VRAM занята таблицами планов, спрайтов и скролла, и под тайлы остаётся примерно 1300–1500 штук (см. [раскладку VRAM](vram-layout.md)).

### Переиспользование

Тайл хранится один раз, а показываться может сколько угодно раз: в таблице плана в сотне клеток может стоять один и тот же номер тайла. Кроме того, при использовании тайл можно:

- отразить по горизонтали и/или вертикали (биты H и V);
- раскрасить любой из 4 палитр.

Так один тайл даёт до 16 вариантов (4 палитры × 4 отражения), не занимая лишней памяти. Флаги задаются в [таблице имён](planes.md#слово-клетки) или в [записи спрайта](sprites.md).

## Как с этим работать

1. Подготовить графику в 16 цветах на тайл (15 видимых + прозрачный).
2. Разрезать на тайлы 8×8 и закодировать в 4 бита на пиксель (этим занимаются конвертеры, см. [Графика и конвертеры](../../tools/graphics.md)).
3. Загрузить в VRAM: установить адрес записи и вывести 32 байта на тайл через порт данных, а для больших объёмов использовать [DMA](dma.md).

## Примеры

Тайл «кружок»:

```m68k
Tile_Circle:
    dc.l $00111100
    dc.l $01222210
    dc.l $12233221
    dc.l $12333321
    dc.l $12333321
    dc.l $12233221
    dc.l $01222210
    dc.l $00111100
```

Загрузка этого тайла как тайла №1 (адрес `$0020`):

```m68k
VDP_DATA    equ $C00000
VDP_CTRL    equ $C00004

    move.l  #$40200000, (VDP_CTRL).l    ; запись в VRAM, адрес $0020
    lea     Tile_Circle, a0
    moveq   #8-1, d0
.loop:
    move.l  (a0)+, (VDP_DATA).l         ; одна строка тайла = 4 байта
    dbra    d0, .loop
```

Как получается команда `$40200000`, объяснено в [Портах и командах](ports-and-commands.md).

## Подводные камни

- Индекс 0 всегда прозрачный. Если нарисовать им чёрный контур, контур пропадёт. Для чёрного нужен отдельный индекс.
- Тайл 0 обычно оставляют пустым: незаполненные клетки таблицы плана (нулевые слова) показывают именно его.
