# Порты и команды

68000 общается с VDP через порты в своём адресном пространстве. Через порт управления выполняется запись в регистры и установка адреса в памяти VDP, через порт данных идут сами данные.

## Как устроено

### Порты

| Адрес | Название | Назначение |
|---|---|---|
| `$C00000` | порт данных (data port) | запись и чтение VRAM, CRAM, VSRAM по текущему адресу |
| `$C00004` | порт управления (control port) | запись в регистры, установка адреса, чтение статуса |
| `$C00008` | HV-счётчик | текущая строка и горизонтальная позиция луча |

Шина данных 68000 — 16-битная. Запись длинного слова (`move.l`) в порт — это две последовательные записи по 16 бит: сначала старшее слово, потом младшее.

### Запись в регистр

В порт управления пишется одно слово:

```
 15 14 | 13 ...... 8 | 7 ......... 0
  1  0 | номер рег.  |   значение
```

```
слово = $8000 | (номер_регистра << 8) | значение
```

```m68k
    move.w  #$8174, $C00004   ; регистр $01 = $74
    move.w  #$8C81, $C00004   ; регистр $0C = $81 (режим H40)
    move.w  #$8F02, $C00004   ; регистр $0F = $02 (автоинкремент 2)
```

Список регистров — на странице [Регистры](registers.md).

### Установка адреса: команда из двух слов

Чтобы читать или писать память VDP, в порт управления посылается команда. Ей нужно 16 бит адреса (VRAM — 64 КБ) и 6 бит кода операции, всего 22 бита. В одно слово это не помещается, поэтому команда состоит из двух слов:

```
Первое слово:   CD1 CD0 A13 A12 A11 A10 A9 A8 A7 A6 A5 A4 A3 A2 A1 A0
Второе слово:    0   0   0   0   0   0   0  0 CD5 CD4 CD3 CD2  0  0 A15 A14
```

- `A15…A0` — адрес в памяти VDP.
- `CD5…CD0` — код операции: какая память и что делать.

Как VDP отличает команду от записи в регистр: если два старших бита первого слова равны `10`, это запись в регистр, и второго слова VDP не ждёт.

### Коды операций

| CD5…CD0 | Операция |
|---|---|
| `000001` | запись в VRAM |
| `000011` | запись в CRAM |
| `000101` | запись в VSRAM |
| `000000` | чтение VRAM |
| `001000` | чтение CRAM |
| `000100` | чтение VSRAM |
| CD5 = 1 | та же операция, но через [DMA](dma.md) |

### Формулы

Из раскладки битов получаются готовые формулы для 32-битной команды (старшая половина — первое слово):

```
VRAM, запись:   $40000000 | ((адрес & $3FFF) << 16) | (адрес >> 14)
CRAM, запись:   $C0000000 | (адрес << 16)
VSRAM, запись:  $40000010 | (адрес << 16)
```

Откуда берутся константы:

- **VRAM, запись** (код `000001`): CD0 = 1 — это бит 14 первого слова, отсюда `$4000`. Младшие 14 бит адреса идут в первое слово (`<< 16` ставит их в старшую половину), два старших бита (A15, A14) — в младшие биты второго слова (`>> 14`).
- **CRAM, запись** (код `000011`): CD1 = CD0 = 1 → `$C000`. CRAM маленькая (128 байт), старшие биты адреса не нужны.
- **VSRAM, запись** (код `000101`): CD0 = 1 → `$4000` в первом слове, CD2 = 1 → бит 4 второго слова → `$0010`.

### Пример разбора

Адрес `$C18A` в VRAM, запись:

```
первое слово  = $4000 | ($C18A & $3FFF) = $4000 | $018A = $418A
второе слово  = $C18A >> 14                             = $0003
команда       = $418A0003
```

То же самое можно записать двумя `move.w`:

```m68k
    move.w  #$418A, $C00004
    move.w  #$0003, $C00004
```

Посчитать команду для любого адреса можно в [калькуляторе команд VDP](../../interactive/vdp-command.md).

### Автоинкремент

После каждой записи или чтения через порт данных VDP **сам прибавляет к текущему адресу** значение [регистра](registers.md) `$0F`. Без этого перед каждым словом пришлось бы заново посылать команду адреса.

```
Адрес $C000, автоинкремент 2:
  move.w #1, $C00000   → записано в $C000, адрес стал $C002
  move.w #2, $C00000   → записано в $C002, адрес стал $C004
```

| Значение | Применение |
|---|---|
| 2 | обычная последовательная запись слов |
| 128 | при плане шириной 64 клетки каждая запись попадает в следующую строку того же столбца: запись **столбца** таблицы (см. [Длинный уровень](../../cookbook/level-streaming.md)) |
| 4 | в таблице HScroll — писать только значения Plane A, перескакивая через B |

### Регистр статуса

Чтение слова из порта управления возвращает статус VDP. Полезные биты:

| Бит | Значение |
|---|---|
| 6 | на какой-то строке превышен лимит спрайтов |
| 3 | идёт VBlank |
| 1 | идёт DMA |
| 0 | консоль PAL |

## Как с этим работать

Удобно завести макрос для команды записи в VRAM:

```m68k
VDP_DATA    equ $C00000
VDP_CTRL    equ $C00004

VRAM_WRITE  macro addr
    move.l  #($40000000|(((\addr)&$3FFF)<<16)|((\addr)>>14)), (VDP_CTRL).l
    endm

    VRAM_WRITE $C18A
    move.w  #$0001, (VDP_DATA).l
```

> Синтаксис макросов зависит от ассемблера. Код не собирался.

## Подводные камни

- Команда адреса — два слова. Если между ними вклинится другая запись в порт управления (например, из обработчика прерывания), VDP получит мусор. Запись команды не должны разрывать прерывания, которые сами работают с VDP.
- Без автоинкремента (значение 0) все записи пойдут по одному адресу.
