# Смена палитры посреди кадра (вода)

**Задача:** часть экрана ниже линии воды должна выглядеть «подводной» — с другими цветами. **Решение:** [прерывание HInt](../hardware/vdp/timing.md#hint-горизонтальное) на строке уровня воды подменяет палитру, а в начале следующего кадра палитра возвращается.

## Идея

```
строка 0     ┌────────────────────────┐
             │  обычная палитра       │
строка 150   ├─ HInt: подменить CRAM ─┤ ← уровень воды
             │  «подводная» палитра   │
строка 223   └────────────────────────┘
VBlank:      вернуть обычную палитру
```

Так в Sonic сделана вода: ниже линии воды палитра подменяется на синеватую.

Тот же приём с [цветом фона](../hardware/vdp/palettes.md#цвет-фона-backdrop) даёт градиент неба: HInt каждые несколько строк меняет регистр `$07`.

## Как с этим работать

1. Включить HInt: бит 4 регистра `$00`.
2. Задать счётчик строк в регистре `$0A`.
3. В обработчике HInt (уровень 4) записать новые цвета в CRAM.
4. В обработчике VInt восстановить исходную палитру.

Самый простой вариант — сменить только цвет фона:

```m68k
VDP_CTRL    equ $C00004

HIntHandler:
    move.w  #$8711, (VDP_CTRL).l    ; цвет фона: палитра 1, цвет 1
    rte
```

## Подводные камни

- Обработчик HInt должен быть коротким: следующая строка начинается очень скоро.
- Если основной код в этот момент посылает команду адреса VDP, обработчик, пишущий в VDP, её разорвёт (см. [Порты и команды](../hardware/vdp/ports-and-commands.md#подводные-камни)).
