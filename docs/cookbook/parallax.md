# Параллакс построчным скроллом

**Задача:** дальние объекты (облака, горы) должны двигаться медленнее ближних, создавая ощущение глубины. **Решение:** разная скорость [скролла](../hardware/vdp/scrolling.md) у Plane A и Plane B, а для большего числа «слоёв» — построчный горизонтальный скролл.

## Идея

Простой вариант — два слоя:

```
Plane A (передний план):  hscroll = −cameraX
Plane B (дальний фон):    hscroll = −cameraX / 2
```

Построчный режим позволяет разрезать один план на полосы с разной скоростью:

```
строки   0– 63:  облака     hscroll = −cameraX / 8   (почти стоят)
строки  64–127:  горы       hscroll = −cameraX / 4
строки 128–223:  земля      hscroll = −cameraX       (в полную скорость)
```

## Код

Буфер HScroll в RAM в аппаратном формате (пары `[A][B]` на каждую строку). Заполняется каждый кадр, в VBlank уходит в таблицу HScroll через [DMA](../hardware/vdp/dma.md):

```c
#define LINES 224

s16 hscrollBuf[LINES * 2];   // [A][B] для каждой строки

void updateParallax(s32 cameraX)
{
    for (u16 line = 0; line < LINES; line++) {
        s16 b;
        if (line < 64)       b = -(cameraX >> 3);   // облака
        else if (line < 128) b = -(cameraX >> 2);   // горы
        else                 b = -cameraX;          // земля

        hscrollBuf[line * 2]     = -cameraX;        // Plane A
        hscrollBuf[line * 2 + 1] = b;               // Plane B
    }
    // в VBlank: DMA hscrollBuf → таблица HScroll (224 × 2 слова)
}
```

Режим построчного горизонтального скролла включается регистром `$0B` (см. [Скроллинг](../hardware/vdp/scrolling.md#режимы)).

### Вариации

- **Волны и марево**: значение для строки — синусоида от номера строки и времени.
- **Плавный градиент скорости**: скорость меняется не полосами, а от строки к строке (пол в перспективе).

## Подводные камни

- Полный буфер — 896 байт на кадр. Это заметная часть бюджета DMA в VBlank. Если полос немного, можно использовать режим «по 8 строк».
- Значения скролла нужно отправлять в VBlank, иначе полосы будут дёргаться.
