## Насколько можно доверять странице

Вверху каждой страницы есть плашка со статусом:

| Плашка | Значение |
|---|---|
| **Заготовка** | страница ещё не написана, есть только план |
| **Не сверено с первоисточниками** | текст есть, но факты не проверены по документации |
| **Сверено с источниками** | факты сверены с документами из раздела [Источники](sources/index.md) |
| **Проверено в эмуляторе** | код и поведение проверены в эмуляторе |
| **Проверено на железе** | проверено на реальной консоли |

Подробнее — в [Правилах оформления](about/conventions.md).

## Как читать

- **На сайте** — поиск вверху работает по всему справочнику.
- **В Obsidian** — откройте папку `docs/` как хранилище (vault). Ссылки, плашки и диаграммы работают и там.
- **Хотите помочь** — см. [Как вести справочник](about/contributing.md).
