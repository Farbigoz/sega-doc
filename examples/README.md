# Примеры

Полные примеры кода к справочнику. Каждый пример — отдельный маленький проект, который собирается в ROM и показывает одну тему.

> Пока пусто. Примеры появятся вместе с пайплайном «сборка → запуск в эмуляторе → скриншот» (см. `docs/about/roadmap.md`, этап 3).

## Структура

```
examples/
  sgdk/                       примеры на C + SGDK
    01-tile-on-plane/
      README.md               что показывает, к какой странице относится, как собрать
      src/main.c
      res/                    ресурсы (png, .res)
      screenshot.png          что должно получиться на экране
  asm/                        примеры на ассемблере 68000
    01-tile-on-plane/
      README.md
      src/main.s
      screenshot.png
```

## Правила

- Имя папки: `NN-название` в `kebab-case`, номер — порядок изучения.
- Один пример — одна тема. Пример минимален: только то, что нужно для темы.
- В `README.md` примера:
  - что показывает пример и ссылка на страницу справочника;
  - как собрать и запустить;
  - статус: собирается / проверен в эмуляторе (каком, версия) / проверен на железе.
- `screenshot.png` — снимок экрана эмулятора после запуска. Он показывает, что именно должен сделать код.
- В страницы справочника код вставляется через `--8<-- "examples/..."`, а не копируется.
- Артефакты сборки (`out/`, `build/`) не коммитим.
